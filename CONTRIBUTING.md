# Contributing

## Process

- All changes must be submitted as pull requests — no direct pushes to `main`.
- CI must pass before a PR can be merged. Run `npm test` locally before opening one.
- PRs should include a clear description of what changed and why (use the PR template).

## Running tests

```bash
npm test          # run once
npm run test:ui   # visual dashboard
```

All 162 tests should be green.
